DEAD//STAT — SELEKTA / VHS EDITION

ЗАПУСК
1. Распакуйте архив.
2. Откройте index.html в современном браузере или запустите папку через VS Code + Live Server.
3. Для загрузки статистики требуется интернет.

ВОЗМОЖНОСТИ
- Поиск игрока по Steam ID64, Steam ID3, ссылке на Steam-профиль или имени.
- Профиль: победы, поражения, Win Rate, K/D/A, KDA, Last Hits, Denies, Net Worth и Souls/Min.
- Форма последних матчей и серия побед/поражений.
- Аналитика по героям.
- Каталог игровых персонажей.
- История матчей и разбор составов с доступными показателями участников.
- VHS/CRT оформление: scanlines, шум, мерцание, виньетка и экранная индикация.
- Telegram: https://t.me/shpundikkid

ИСТОЧНИК ДАННЫХ
Открытый Deadlock API: https://api.deadlock-api.com/docs
История и полнота данных зависят от доступности матчей в источнике. Некоторые подробные поля могут отсутствовать.

ПРИМЕЧАНИЕ
Это неофициальный фан-проект. DEAD//STAT не связан с Valve. Данные API загружаются напрямую из браузера; при ограничениях API, CORS, сетевых сбоях или лимитах запросов отдельные разделы могут быть недоступны.

ОБНОВЛЕНИЕ: STEAM-ПРОФИЛИ И CRT-МОНИТОР
- Весь сайт теперь расположен внутри более выраженной рамки CRT-монитора с затемнённой окантовкой, стеклянным бликом и VHS-сканированием.
- При поиске игрока дополнительно запрашивается публичный Steam-профиль через GET /v1/players/steam?account_ids=...
- В досье показываются Steam-аватар, никнейм и ссылка на профиль Steam. При недоступности аватара используется портрет героя как запасное изображение.
- Поиск по имени получает Steam-профиль непосредственно из результатов steam-search.
- Для работы требуется интернет и доступность Deadlock Community API.

ОБНОВЛЕНИЕ: ИНТЕРАКТИВНЫЙ АРХИВ ПЕРСОНАЖЕЙ
- Карточки героев кликабельны и открывают полноэкранное досье в стиле CRT/VHS.
- Досье показывает игровой портрет, роль/теги, доступную биографию, стиль игры и базовые характеристики из ассетов.
- Для слотов signature/innate выполняется дополнительный запрос к API игровых ассетов способностей; если API не возвращает описание, интерфейс явно сообщает об отсутствии данных.
- Если предварительно загружен профиль игрока, в досье героя показывается его личная статистика на этом персонаже (матчи, победы, K/D/A и время в игре).
- Закрытие досье: кнопка X, клик по затемнению или клавиша Escape.
